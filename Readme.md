# Scissors API

A backend service built with Node.js, Express, and MongoDB, with a strong focus on testing using Jest. This project demonstrates writing reliable, testable backend code.

## 🚀 Features

- RESTful API endpoints
- MongoDB integration for data persistence
- Unit and functional testing with Jest
- Structured and modular backend architecture
- Error handling and validation

## 🛠️ Tech Stack

- Node.js
- Express.js
- MongoDB (Mongoose)
- Jest (Testing)
- JavaScript / TypeScript
